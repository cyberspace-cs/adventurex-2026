## 📚 学习要点

### 1. 硬件 + AI 的结合
- 智能项圈（Pengiu）、四足机器人（Night Watch）、耳机（Choose Life Agent）、智能眼镜（Syna）
- 共同点：**AI 是大脑，硬件是身体**
- 开发思路：先做 AI 软件原型，再集成硬件

### 2. 个人陪伴产品设计
- **同意干预**原则：检测到问题 → 先问用户 → 再行动
- **非侵入式**设计：不打扰用户，默默陪伴
- **情绪感知**：检测疲劳/情绪状态
- **数字生命**：给物品/玩偶赋予人格和记忆（Toy Diary）

### 3. 黑客松产品设计
- **MVP 原则**：一个 killer feature > 五个半吊子功能
- **Demo 优先**：先做能演示的核心流程
- **成本控制**：硬件成本要低，快速迭代
- **多赛道投稿**：一个项目投多个赛道，增加获奖概率

### 4. Web3 + AI 结合
- Toy Diary 用 Injective 做数据存储
- ShiftX 也获 Injective AI 极客奖
- 趋势：AI + Web3 是黑客松热门方向
