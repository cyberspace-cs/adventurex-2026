## 🥇 一等奖项目

### 1. Night Watch（四足机器人）
- **赛道**：Dimensional Track 一等奖
- **团队**：Night Watch（印尼 + 阿根廷 + 中国 国际团队）
- **方向**：AI 机器人 + 个人陪伴
- **项目简介**：基于 Unitree Go2 四足机器人的 AI 陪伴机器人
- **核心功能**：
  - **疲劳检测**：实时监测用户身体状态，检测疲劳/倦怠迹象
  - **同意干预**：检测到疲劳后先征得用户同意，再引导休息
  - **护送功能**：陪伴用户前往休息区域
- **技术栈**：Unitree Go2 四足机器人 + AI 视觉 + 语音交互
- **源码仓库**：[4MaticLab/night-shift](https://github.com/4MaticLab/night-shift)（已 fork → [cyberspace-cs/night-shift](https://github.com/cyberspace-cs/night-shift)）

### 2. AI 冰箱精灵
- **赛道**：涂鸦智能「破界者：用 AI 重写生活脚本」一等奖
- **方向**：智能家居 + AI 生活助手
- **项目简介**：AI 冰箱贴，实时同步食材库存，AI 推荐菜谱、规划三餐
- **核心功能**：
  - **库存管理**：实时同步冰箱食材库存
  - **菜谱推荐**：基于库存 AI 推荐菜谱
  - **三餐规划**：智能规划每日饮食
  - **多线程倒计时**：与手机联动，同时煮多锅食物计时
- **成本估算**：硬件成本 ~300 元，售价 ~500 元

## 📚 学习要点

### 1. 硬件 + AI 的结合
- 智能项圈（Pengiu）、四足机器人（Night Watch）、冰箱贴（AI 冰箱精灵）
- 共同点：**AI 是大脑，硬件是身体**
- 开发思路：先做 AI 软件原型，再集成硬件

### 2. 个人陪伴产品设计
- **同意干预**原则：检测到问题 → 先问用户 → 再行动（Night Watch）
- **非侵入式**设计：不打扰用户，默默陪伴
- **情绪感知**：检测疲劳/情绪状态

### 3. 黑客松产品设计
- **MVP 原则**：一个 killer feature > 五个半吊子功能
- **Demo 优先**：先做能演示的核心流程
- **成本控制**：硬件成本要低，快速迭代
